# Five-minute demo

1. Explain: a phone number becomes an email identity.
2. Open the responsive client, enter a phone number, and verify demo OTP `123456`.
3. Show the mobile conversation list, open a conversation, and send a reply.
4. Resize to desktop to show the Gmail-style two-pane inbox.
5. Compose a new message including CC and BCC.
6. Show `docker compose up -d --build`, `/health`, and Mailpit at port 8025.
7. Explain the `/api/twilio/sms` and `/api/twilio/voice` integration routes and production secret configuration.
